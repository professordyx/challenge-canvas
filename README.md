# Challenge Canvas Builder

**Diagnose complex problems and frame organizational challenges before jumping to solutions.**

A twelve-block challenge canvas, an AI assistant (Google Gemini), and real-time collaboration —
built as a Design Science Research (DSR) artifact by [Diocélio Goulart](https://dioceliogoulart.com.br).

## 🇧🇷 Português

O **Challenge Canvas Builder** é um aplicativo web que estrutura desafios
organizacionais complexos antes de partir para a solução. Reúne doze blocos de
enquadramento (contexto, problema, impacto, stakeholders, declaração do desafio,
critérios de sucesso, restrições, recursos, hipóteses, abordagem, governança e
entregáveis), um assistente de IA para refinar e avaliar o canvas, e
compartilhamento com edição em tempo real.

O produto foi concebido como artefato de pesquisa em administração sob a metodologia
**Design Science Research** (Peffers et al., 2007; Hevner et al., 2004). A
documentação completa — produto, arquitetura e a trilha de construção via DSR — está
em **[docs/pt-BR.md](./docs/pt-BR.md)**.

- **O que resolve:** disciplina o enquadramento de problemas, evitando o salto
  precoce para a solução.
- **Stack:** React 18 + Vite 5 + TypeScript + shadcn-ui/Tailwind no frontend;
  Supabase (PostgreSQL, Auth, Storage, Edge Functions, Realtime) no backend; Google
  Gemini para a IA.
- **Idiomas do produto:** Português e Espanhol.

```bash
git clone https://github.com/professordyx/challenge-canvas.git
cd challenge-canvas && npm install && npm run dev
```

<!-- ====================== ENGLISH ====================== -->

## 🇬🇧 English

**Challenge Canvas Builder** is a web application that structures complex
organizational challenges before moving to a solution. It brings together twelve
framing blocks (context, problem, impact, stakeholders, challenge statement, success
criteria, constraints, resources, hypotheses, approach, governance, and
deliverables), an AI assistant to refine and evaluate the canvas, and sharing with
real-time editing.

The product was conceived as a business-administration research artifact under the
**Design Science Research** methodology (Peffers et al., 2007; Hevner et al., 2004).
Full documentation — product, architecture, and the DSR construction trail — is in
**[docs/en.md](./docs/en.md)**.

- **What it solves:** it disciplines problem framing and prevents the early jump to
  a solution.
- **Stack:** React 18 + Vite 5 + TypeScript + shadcn-ui/Tailwind on the frontend;
  Supabase (PostgreSQL, Auth, Storage, Edge Functions, Realtime) on the backend;
  Google Gemini for the AI.
- **Product languages:** Portuguese and Spanish.

```bash
git clone https://github.com/professordyx/challenge-canvas.git
cd challenge-canvas && npm install && npm run dev
```

➡️ **[Read the documentation in English](./docs/en.md)**
